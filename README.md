# Umi

Voice-first buddy for your Mac.

Umi is a native macOS app written in Swift and SwiftUI. You talk to it out loud, and it sees your screen, points at things and helps you work them out. It is in early development.

- The model runs on your own Claude Code or Codex subscription. An API key (for example Claude API credits) may be added later as another option.
- Speech-to-text and text-to-speech use Deepgram for now. The provider may change later, for example to a platform with free credits.
